One line — a single original dad joke, written to be told out loud at the dinner table. My son told me to surprise him for dinner, so I made a sandwich and called it a wrap: the setup sounds like a chore, the punchline turns on one word, and the groan arrives right at the end. Run it and it writes the joke to `entry.txt`, exactly one line, 85 characters.

## Run it

```sh
python3 main.py
```
